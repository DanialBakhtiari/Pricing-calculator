# Rule — دسترس‌پذیری (WCAG 2.1 AA)

**اعمال:** هر کامپوننت تعاملی و هر نمودار.

## پایه
- کنتراست متن ≥ 4.5:1، عناصر بزرگ/آیکن ≥ 3:1.
- فوکوس همیشه دیده‌شود (ring برند، نه `outline:none` بدون جایگزین).
- کل اپ با کیبورد قابل‌استفاده: Tab/Shift+Tab، Enter/Space، Esc برای بستن.
- هدف لمس ≥ 44×44px.
- احترام به `prefers-reduced-motion`.

## فرم‌ها
- هر input یک `<label>` متصل دارد. خطا با `aria-invalid` + `aria-describedby`.
- پیام خطا متنی و کنار فیلد (نه فقط رنگ).

## tooltip («!»)
- آیکن قابل‌فوکوس (button) با `aria-label`. محتوا با `aria-describedby`.
- در موبایل tap باز/بسته شود؛ با Esc بسته شود.

## نمودار
- هر چارت `role="img"` + `aria-label` خلاصه‌ی عددی.
- یک جدول داده‌ی متنیِ هم‌ارز (می‌تواند visually-hidden باشد) برای screen-reader.
- رنگ تنها حامل معنا نباشد؛ محک‌ها متن/آیکن هم داشته باشند.

## محک پذیرش
- اجرای axe (jsx-a11y + تست) بدون violation جدی.
- Lighthouse A11y ≥ 95.
